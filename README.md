# Logica.JS

> Treinando conceitos de lógica de programação para prova.

## Sobre o Projeto
Este repositório foi criado com o objetivo de consolidar meus conhecimentos em lógica de programação utilizando a linguagem JavaScript. Atualmente, o foco dos estudos está nas estruturas de repetição (laços/loops).

## Tecnologias Utilizadas
*   **JavaScript** (ES6+)
*   **Node.js** (para execução dos scripts no terminal)

## Estrutura do Repositório
O projeto está organizado da seguinte forma:

  - `lacos-repeticao.js`: Exercícios com o laço `for` (contagem, tabuada, soma).
  - `lacos-while.js`: Exercícios com o laço `while` (contagem regressiva, múltiplos de 5, controle de estoque).
  - `lacos-dowhile.js`: Exercício com o laço `do...while`.
